## 2. Server Environment Variables (`server/.env`)

The Express gateway reads its configuration from `server/.env`. Below is the complete specification:

| Variable Name | Required? | Default / Example Value | Description & Security Boundary |
|---|:---:|---|---|
| `SF_LOGIN_URL` | **Yes** | `https://login.salesforce.com` | Target Salesforce OAuth authority. Use `https://test.salesforce.com` for sandboxes. |
| `SF_CLIENT_ID` | **Yes** | *(Consumer Key from Connected App)* | OAuth 2.0 Consumer Key generated by Salesforce Connected App. |
| `SF_CLIENT_SECRET` | **Yes** | *(Consumer Secret from Connected App)* | OAuth 2.0 Consumer Secret. Stored **strictly** on backend; never exposed to browser. |
| `SF_REDIRECT_URI` | **Yes** | `http://localhost:3001/auth/salesforce/callback` | Callback URL matching Connected App OAuth settings exactly. |
| `SF_API_VERSION` | **Yes** | `v60.0` | Salesforce REST API and Apex REST version. |
| `SESSION_SECRET` | **Yes** | *(Use a separately generated random secret of at least 32 characters)* | Cryptographic secret for signing session cookies (`civictax.sid`). |
| `FRONTEND_URL` | **Yes** | `http://localhost:5173` | Designated React origin allowed for CORS requests with credentials. |
| `PORT` | **Yes** | `3001` | TCP port where Express Gateway listens. |
| `NODE_ENV` | **Yes** | `development` | Runtime environment mode (`development` or `production`). |

## 3. Network & Session Security Policies

1. **Cross-Origin Resource Sharing (CORS)**:
   - Configured in `server/src/server.ts` to allow **only** `http://localhost:5173`.
   - `credentials: true` enables browser cookie exchange for session authentication.
2. **HttpOnly Cookie Invariance**:
   - Session identifiers are encapsulated inside `civictax.sid`.
   - `httpOnly: true` prevents client-side scripts from reading session tokens, mitigating Cross-Site Scripting (XSS) risks.
   - `sameSite: 'lax'` prevents Cross-Site Request Forgery (CSRF).
3. **Standby Mode Fallback**:
   - When `SF_CLIENT_ID` is empty or the org is unauthenticated, the gateway returns:
     ```json
     { "salesforceConnected": false, "status": "HEALTHY", "dataProvider": "LocalRepository" }
     ```
   - This guarantees that property registration, tax calculations, payments, grievances, and reports continue operating without interruption.
