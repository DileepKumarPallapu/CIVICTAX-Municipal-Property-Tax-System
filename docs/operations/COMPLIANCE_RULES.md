# CivicTax Compliance Monitoring & Explainable Audit Rules

## 1. Compliance Architecture

The CivicTax Compliance Engine operates on an explainable, deterministic rule-based framework. Every alert generated by the system is strictly classified as a **Review Indicator** rather than proof of wrongdoing or malpractice, ensuring transparent and legally sound municipal operations.

---

## 2. Explainable Rule Registry

| Rule ID | Rule Name | Detection Logic | Evidence Reference | Severity |
| :--- | :--- | :--- | :--- | :--- |
| **CMP-001** | Duplicate Property Reference | Multiple properties registered with identical door/survey number or GIS parcel hash. | Property IDs, Registration Dates, GIS Lat/Lng | `HIGH` |
| **CMP-002** | Invalid Property Dimensions | Built-up area exceeds plot size or is $< 50\text{ sq ft}$ or $> 500,000\text{ sq ft}$. | Plot Dimension vs Declared Built-up Area | `MEDIUM` |
| **CMP-003** | Missing Active Tax Rate | Assessment calculation triggered for a zone/category combination with no active tax rate for the fiscal year. | Assessment Date, Category, Zone Rate Master | `CRITICAL` |
| **CMP-004** | Assessment Calculation Mismatch | Authoritative calculation does not match stored assessment total: $|(\text{Area} \times \text{Rate} + \text{Penalty} - \text{Discount}) - \text{Total}| > 0.01$. | Formula breakdown, Applied Rate, Stored Total | `CRITICAL` |
| **CMP-005** | Duplicate Transaction Hash | Two or more payment records sharing the identical gateway reference or bank transaction UTR. | Transaction UTR, Gateway ID, Payment Timestamps | `CRITICAL` |
| **CMP-006** | Payment Reconciliation Mismatch | Sum of verified successful payments exceeds or discrepancies against recorded assessment credit balance. | Payment Receipt Ledger vs Assessment Balance | `HIGH` |
| **CMP-007** | Service SLA Breach | Turnaround time for grievance, reassessment, or transfer exceeds maximum statutory municipal threshold. | SLA Target Date vs Current Date / Completion Date | `MEDIUM` |
| **CMP-008** | Workflow Inconsistency | Property marked as verified or assessment finalized without mandatory supporting document references. | Document Vault Index, Verification Timestamp | `HIGH` |

---

## 3. Explainability and Remediation Protocol

1. **Deterministic Explanations**: Alerts display the formula, detected values, expected values, and delta.
2. **Review Indicator Principle**: An alert initiates an officer review workflow; it does not lock a citizen's constitutional right to submit payments or file appeals.
3. **Audited Resolution Notes**: Officers resolving an alert must submit a formal resolution justification which is recorded in the immutable compliance audit log.
