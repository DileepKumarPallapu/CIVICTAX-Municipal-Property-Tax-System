# CivicTax 2.0 Design System Specification

## 1. Brand Identity & Tagline

- **Brand**: CIVICTAX
- **Tagline**: *Smart Property Tax. Transparent Governance.*
- **Aesthetic Benchmark**: Stripe, Linear, Vercel GovTech enterprise quality.

## 3. Typography & Spacing Scale

- **Typefaces**: `Plus Jakarta Sans`, `Inter`, `system-ui`.
- **Card Radii**: `rounded-2xl` (`1rem`) and `rounded-3xl` (`1.5rem`) for macro layout modules.
- **Elevation**: Layered drop shadows (`shadow-subtle`, `shadow-card`, `shadow-elevated`).
- **Focus Rings**: Accessible focus indicators (`focus:ring-2 focus:ring-[#2563EB]/40`).
